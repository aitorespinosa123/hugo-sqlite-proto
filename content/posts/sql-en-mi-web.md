## Mi primera práctica con SQL

En esta práctica de Implantación de Aplicaciones Web estoy aprendiendo a utilizar SQLite junto con Hugo.

SQLite permite organizar la información de las publicaciones y generar archivos JSON durante la construcción de la página.

Gracias a esto podemos mostrar etiquetas y realizar búsquedas sin necesitar una base de datos funcionando en el servidor.
